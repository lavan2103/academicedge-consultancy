# AcademicEdge Consultancy Website

A responsive one-page consultancy website.

## Files
- index.html
- styles.css
- script.js

## How to use
Open `index.html` in Chrome.

## Customize
In `index.html`, replace:
- hello@academicedgeconsultancy.com
- +91 00000 00000
- testimonials
- service descriptions
- business text

## Publish
You can upload the folder to GitHub and deploy with GitHub Pages, Netlify, Vercel, or any normal web host.

## Contact form
The current form is a front-end demo. Connect it to Formspree, EmailJS, or your own backend to receive inquiries.
